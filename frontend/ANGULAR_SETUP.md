# Angular setup for Stages 40–47

Use the existing Angular project from the earlier stages. The code in `src/`
replaces the starter shell and adds:

- Stage 40 application shell
- Stage 41 state domains
- Stage 42 API service
- Stage 43 file selection
- Stage 44 drag and drop
- Stage 45 client-side PDF validation
- Stage 46 multipart upload request
- Stage 47 upload/server-processing state display

The frontend intentionally does **not** implement PDF parsing, embeddings,
Chroma, prompt construction, Hugging Face, or Groq.
